ReportaTuCiudad — Boceto del diagrama de arquitectura

Fase 1: Planteamiento del proyecto · Prototipo serverless en AWS · Infraestructura como código con Terraform

Amazon API GatewayPunto de entrada HTTPS de la API REST del prototipo.
AWS LambdaLógica de reportes, comentarios, confirmaciones y estados.
Amazon DynamoDBUsuarios, reportes, comentarios e historial de estados.
Amazon S3Fotografías, evidencias y sitio estático del frontend.
Amazon SQS + SNSEventos asíncronos y notificaciones por correo al ciudadano.
IAM · Secrets Manager · CloudWatchPermisos mínimos, credenciales y monitoreo del sistema.
TerraformTodos los recursos se crean y destruyen desde los módulos .tf del repositorio.
Flujo principal: ciudadano → frontend → API Gateway → Lambda → DynamoDB / S3 → SQS → SNS → notificación al ciudadano.
